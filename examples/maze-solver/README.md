# Maze Solver

The objective of the maze solver is to create a program that will import a maze from a text file, load it into a datastructure, then proceed to solve the maze. The output should match the corresponding maze in the solutions directory.

All mazes taken from: https://www.asciiart.eu/ascii-maze-generator

## Language Challenges

There are several language challenges that are resolved here. It tests text io both from stdin and stdout as well as basic usage of datastructures and algorithms.
